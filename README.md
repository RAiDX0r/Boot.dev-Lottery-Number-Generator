# Boot.dev-Lottery-Number-Generator
Personal Project 1 on Boot.dev backend developer course.

Use games.json to change and add new lottery websites.

## Date Parse String — Valid Placeholders

| Token     | Meaning              | Example            |
|-----------|----------------------|--------------------|
| {DotW}    | Day of the week      | Wednesday / Wed    |
| {Month}   | Month name/number    | February / Feb / 2 |
| {Day}     | Day of the month     | 17                 |
| {Year}    | Four-digit year      | 2026               |

The `date_parse_string` template must match the source site's date text exactly,
including literal punctuation and whitespace between tokens.
